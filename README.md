# What is ktane-Markdown?
This repository is meant to be the home for guides and answers to questions regarding Keep Talking and Nobody Explodes, primarily its modding scene. Every markdown file here is meant to answer some questions you may have about the game, whether you would like to create mods, play mods, contribute to the manual repo, or just want to learn more.

# How can I help?
If there's a topic that you think warrants an easily-accessible guide or answer, you may submit an issue to this repository or write one yourself and send a pull request including it. Refer to [this page](<https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax>) if you're unfamiliar with markdown files and their syntax.
