The basic checklist for creating your first module is as follows:
- Create the manual; anything is fine in the early phases of development, but you will need to have an [HTML](<https://developer.mozilla.org/en-US/docs/Web/HTML#beginners_tutorials>) version of the manual.
- Install [Unity 2017.4.22f1](<https://unity.com/releases/editor/archive>) and the [community modkit](<https://github.com/Qkrisi/ktanemodkit/>).
- Model your module either with the basic shapes/tools Unity provides or with custom models created with software such as [Blender](<https://www.blender.org/>).
- Set up your module then program its functionality using [C#](<https://learn.microsoft.com/en-us/dotnet/csharp/>).
- Add the quality "finishing touches" like pretty textures, sounds, and animations.
- Test your module by building the module and playing it in-game before uploading to the Steam Workshop.
- Provide the manual and create a JSON file so the module can be added to the manual repository.
