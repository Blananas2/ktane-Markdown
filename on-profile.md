Twitch Plays' ON profile (simply the word 'on', it's not an abbreviation) is a [profile](<https://ktane.timwi.de/More/Glossary.html#profile>) that is always on with the purpose of disabling all modules that are known to be currently bugged. When bugs are discovered, the TP moderator role (and the author of the module in question) should be notified with a description and proof of the module not acting as intended so it can be added to the profile. Modules currently disabled via the ON profile are listed here https://discord.com/channels/581624697976913950/744220882129387551 and [this sheet of the TP Scoring Spreadsheet](<https://docs.google.com/spreadsheets/d/1G6hZW0RibjW7n72AkXZgDTHZ-LKj0usRkbAwxSPhcqA/edit?gid=1849453757#gid=1849453757>).
